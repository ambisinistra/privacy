Privacy Policy

Last updated: 25 November 2026

This application ("wrapping-dev") is a personal tool used only by its developer. It accesses Google account data solely to perform the functions the developer has configured for their own account.

Data we access

Through Google OAuth, the application may access data in the developer's own Google account (for example, the account's email address and the Google services the developer has explicitly authorised). No other person's data is accessed.

How data is used

Data is used only to provide the application's own functionality for the developer. It is not used for advertising, profiling, or training of machine-learning models.

Sharing

No data is shared with, sold to, or transferred to third parties.

Storage and retention

Data is not stored beyond what is needed for the application to work. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
